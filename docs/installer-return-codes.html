DeskStats

Installer return codes

Applies to the DeskStats 1.0.1 EXE installer, built with Inno Setup.

Silent installation

/SP- /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

Run setup with administrator privileges. Add /LOG="C:\path\install.log" to collect diagnostic details in an existing directory.

Exit codes

CodeMeaning
0Setup completed successfully.
1Setup could not initialize.
2The user canceled before installation began.
3A fatal error interrupted preparation for the next setup phase.
4A fatal installation error occurred.
5Installation was canceled or aborted, including a suppressed file-operation error.
6The installer debugger terminated setup.
7A preparation check blocked installation, such as an inaccessible existing executable.
8A preparation check blocked installation and requires a restart before retrying.

Codes 1–8 indicate incomplete installation. Code 8 does not mean a successful installation awaiting restart. This build defines no custom success-with-restart code or dedicated codes for network failure, disk capacity, an existing installation, concurrent installation, or security-policy rejection.
